      Contributor Onboarding Roadmap

      Follow this 8-step guide to navigate from newcomer to merged PR in facebook/react.

      1

      Understand the Project

      React is a declarative, efficient, and flexible JavaScript library for building user interfaces.

      Read Documentation
      2

      Set Up the Project

      Install dependencies and ensure initial test suite executes properly in your local developer environment.

      git clone https://github.com/facebook/react.git
cd react
npm install
npm test
      3

      Find a Beginner-Friendly Issue

      Look for issues tagged with good first issue, help wanted, or documentation.

      4

      Create a Dedicated Branch

      Never make commits directly on main or master. Branch off with a concise descriptive name:

      git checkout -b fix/issue-101-anchor-link
      5

      Make Changes & Adhere to Style

      Follow formatting conventions (Prettier/ESLint). Keep changes atomic and directly targeted to the issue.

      Follow Code Guidelines
      6

      Test Your Changes

      Write tests covering new behaviors or regressions. Confirm that all repository linter and test checks pass:

      npm run test
npm run lint
      7

      Create the Pull Request

      Push your branch and open a PR with a clear summary, testing steps, and link the issue:

      Closes #101

### Summary
Fixed broken anchor link in the Quick Start guide.
      8

      Respond to Review & Land It

      Maintainers will review your PR. Address feedback with grace, update your branch, and celebrate your open-source contribution!

      Check GitHub Notifications
